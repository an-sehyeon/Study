# 1. 프로그래밍 언어 코드 해석

## 1.1 공통 풀이 원칙

코드를 눈으로만 읽지 말고 다음 순서로 표를 작성한다.

1. 변수의 초깃값을 적는다.
2. 배열·리스트·객체·포인터가 가리키는 대상을 그린다.
3. 반복문은 회차별로 값을 적는다.
4. 대입문은 오른쪽 값을 먼저 계산한다.
5. 출력 형식까지 확인한다.
6. 이전 대입문을 나중에 다시 계산하지 않는다.

```text
값 변경: 객체나 변수 안의 실제 값이 바뀜
참조 변경: 가리키는 대상만 바뀜
```

## 1.2 C 언어 최종 암기

### 포인터

```c
int a = 10;
int *p = &a;
```

```text
a  : 값 10
&a : a의 주소
p  : a의 주소
*p : p가 가리키는 값 10
```

```c
*p = 20;
```

`p`가 가리키는 실제 변수 `a`의 값이 20으로 변경된다.

### 배열과 포인터

```c
int arr[] = {10, 20, 30};
int *p = arr;
```

```text
arr      = &arr[0]
*p       = arr[0]
*(p + 1) = arr[1]
p[2]     = arr[2]
```

### 구조체

```c
struct Node {
    int value;
    struct Node *next;
};
```

```text
일반 구조체 변수 접근: node.value
구조체 포인터 접근:    p->value
```

```c
p->value
```

는 다음과 같다.

```c
(*p).value
```

### 문자열

C 문자열의 끝에는 널 문자 `'\0'`가 있다.

```c
char s[] = "ABC";
```

실제 저장:

```text
'A' 'B' 'C' '\0'
```

```c
printf("%s", s + 1);
```

출력:

```text
BC
```

### 전위·후위 증감

```c
a = i++;
```

```text
현재 i를 a에 대입
→ i 증가
```

```c
a = ++i;
```

```text
i 증가
→ 증가한 값을 a에 대입
```

### 정수 나눗셈

```c
7 / 2 = 3
7 % 2 = 1
```

실수 결과가 필요하면 피연산자 중 하나를 실수로 만든다.

```c

```

### 출력 형식

| 형식 | 의미 |
|---|---|

| `%.2f` | 소수점 둘째 자리까지 |
| `%c` | 문자 한 개 |
| `%s` | 문자열 |
| `%x` | 16진수 소문자 |
| `%o` | 8진수 |
| `%p` | 주소 |

```text
32를 %x로 출력 → 20
```

### 비트 연산

| 연산자 | 의미 |
|---|---|
| `&` | AND |
| `|` | OR |
| `^` | XOR |
| `~` | NOT |
| `<<` | 왼쪽 이동 |
| `>>` | 오른쪽 이동 |

```text
5 = 0101
3 = 0011

5 & 3 = 0001 = 1
5 | 3 = 0111 = 7
5 ^ 3 = 0110 = 6
```

### 연산자 우선순위 핵심

```text
괄호
→ 단항 연산

→ 관계 연산
→ 비트 AND
→ 비트 XOR
→ 비트 OR
→ 논리 AND
→ 논리 OR
→ 삼항 연산
→ 대입
```

헷갈리면 반드시 괄호를 직접 표시한다.



## 1.3 Java 최종 암기

### 클래스 상속과 인터페이스

```java
class Child extends Parent
```

```java
class Child implements InterfaceName
```

```text
클래스 상속 → extends
인터페이스 구현 → implements
```

### 생성자 호출 순서

```text
부모 생성자
→ 자식 생성자
```

자식 생성자의 첫 줄에서 부모 생성자를 호출할 때:

```java
super();
```

같은 클래스의 다른 생성자를 호출할 때:

```java
this();
```

### 오버로딩과 오버라이딩

| 구분 | 오버로딩 | 오버라이딩 |
|---|---|---|
| 조건 | 같은 이름, 다른 매개변수 | 부모 메서드를 자식이 재정의 |
| 결정 시점 | 컴파일 시점 | 실행 시점 |
| 기준 | 참조 변수와 매개변수의 선언 타입 | 실제 생성된 객체 타입 |

핵심:

```text
오버로딩 선택 → 컴파일 시 선언 타입 기준
오버라이딩 실행 → 런타임 실제 객체 기준
```

### 다형성

```java
Parent p = new Child();
p.method();
```

`method()`가 오버라이딩되어 있다면 `Child`의 메서드가 실행된다.

### 참조형 대입

```java
Box a = new Box();
Box b = a;
```

```text
a와 b가 같은 객체를 가리킨다.
b.value 변경 → a.value도 변경된 것처럼 보임
```

### 배열도 참조형

```java
int[] a = {1, 2, 3};
int[] b = a;
b[0] = 99;
```

```text
a[0]도 99
```

### 문자열 결합

```java
System.out.println(9 + 2 + "2" + "3");
```

왼쪽부터 계산한다.

```text
9 + 2 = 11
11 + "2" = "112"
"112" + "3" = "1123"
```

### `==`와 `equals()`

```text
==       : 기본형 값 비교 / 참조형 주소 비교
equals() : 객체의 내용 비교 목적으로 주로 사용
```

### static

```text
static 멤버 → 클래스에 소속
인스턴스 멤버 → 객체에 소속
```

static 메서드는 일반 인스턴스 메서드처럼 동적 오버라이딩되지 않는다.

### 예외 처리

```java
try {
    // 실행
} catch (Exception e) {
    // 예외 처리
} finally {
    // 예외 발생 여부와 관계없이 일반적으로 실행
}
```

### enum

```java
enum Grade { A, B, C }
```

```text
Grade.values() → 선언된 모든 값
Grade.A.name() → "A"
Grade.A.ordinal() → 선언 순서 0
```

## 2.4 JOIN

### INNER JOIN

양쪽에서 조건이 일치하는 행만 출력한다.

```sql
SELECT *
FROM employee e
JOIN department d
  ON e.dept_id = d.dept_id;
```

### LEFT JOIN

왼쪽 테이블의 모든 행을 유지한다.

```text
오른쪽에 일치하는 행이 없으면 오른쪽 열은 NULL
```

### CROSS JOIN

모든 행의 조합을 만든다.

```text
A 테이블 3행 × B 테이블 4행 = 12행
```

### SELF JOIN

같은 테이블을 별칭으로 나누어 자기 자신과 조인한다.

| 연산자 | 의미 |
|---|---|

## 2.7 제약조건 문법

```sql

    PLAYER_ID INT PRIMARY KEY,
    TEAM_ID INT,
```


| `NOT NULL` | NULL 불가 |
| `CHECK` | 조건에 맞는 값만 허용 |

## 2.11 정규화

### 제1정규형(1NF)

모든 속성값이 원자값이어야 한다.

```text
한 칸에 여러 값 저장 금지
```

### 제2정규형(2NF)

1NF를 만족하고 부분 함수 종속을 제거한다.

```text
복합 기본키의 일부에만 종속되는 일반 속성 제거
```

### 제3정규형(3NF)

2NF를 만족하고 이행 함수 종속을 제거한다.

```text
기본키 → 일반 속성 A → 일반 속성 B
```

### BCNF

모든 결정자가 후보키여야 한다.

### 정규화 암기

```text
도부이결다조
```

```text
1NF: 도메인 원자값
2NF: 부분 함수 종속 제거
3NF: 이행 함수 종속 제거
BCNF: 결정자가 후보키
4NF: 다치 종속 제거
5NF: 조인 종속 제거
```

---

## 2.12 함수 종속

```text
X → Y
```

X 값이 정해지면 Y 값이 하나로 결정된다는 의미다.

| 종류 | 의미 |
|---|---|
| 완전 함수 종속 | 기본키 전체에 종속 |
| 부분 함수 종속 | 복합키의 일부에 종속 |
| 이행 함수 종속 | X → Y, Y → Z로 인해 X → Z |

## 2.13 트랜잭션 ACID

| 특성 | 의미 |
|---|---|
| 원자성 | 전부 실행하거나 전부 취소 |
| 일관성 | 전후 데이터 무결성 유지 |
| 격리성 | 동시에 실행되는 트랜잭션이 서로 방해하지 않음 |
| 영속성 | 완료 결과가 계속 보존 |

```text
원일격영
```

### 병행 제어 문제

| 문제 | 의미 |
|---|---|

## 5.2 큐

```text
FIFO: 먼저 들어온 데이터가 먼저 나감
```

연산:

```text
enqueue: 뒤에 삽입
dequeue: 앞에서 삭제
```

활용:

- 작업 대기열
- 프린터 큐
- BFS

---

## 5.3 원형 큐

배열의 끝과 처음을 논리적으로 연결한다.

```text
다음 위치 = (현재 위치 + 1) % 배열 크기
```

한 칸을 비워 두는 방식:

```text
공백 상태: front == rear
포화 상태: (rear + 1) % size == front
```

---

## 5.4 트리 순회

```text
전위: Root → Left → Right
중위: Left → Root → Right
후위: Left → Right → Root
```

암기:

```text
전위는 루트 먼저
중위는 루트 중간
후위는 루트 마지막
```

## 5.5 DFS와 BFS

| DFS | BFS |
|---|---|
| 깊이 우선 | 너비 우선 |
| 스택·재귀 | 큐 |
| 한 경로를 끝까지 탐색 | 가까운 노드부터 탐색 |

## 5.6 정렬 시간복잡도 최소 암기

| 정렬 | 평균 | 특징 |
|---|---|---|
| 버블 | `O(n²)` | 인접 원소 비교 |
| 선택 | `O(n²)` | 최솟값을 선택해 교환 |
| 삽입 | `O(n²)` | 정렬된 부분에 삽입 |
| 퀵 | `O(n log n)` | 피벗 기준 분할, 최악 `O(n²)` |
| 병합 | `O(n log n)` | 분할 후 병합, 추가 공간 필요 |
| 힙 | `O(n log n)` | 힙 자료구조 이용 |

# 10. 시험장에서 실수하지 않는 방법

1. 문제에서 요구한 답안 언어를 확인한다.
    - 한글 명칭
    - 영문 명칭
    - 영문 약자
    - 출력값
2. 답이 여러 개인 문제는 번호와 순서를 정확하게 맞춘다.
3. SQL은 괄호, 쉼표, 예약어 철자를 확인한다.
4. 코드 문제는 출력 형식까지 확인한다.
    - 줄바꿈
    - 공백
    - 소수점 자릿수
    - 8진수·10진수·16진수
5. 모르는 문제에 오래 머물지 않고 아는 문제부터 작성한다.
6. 코드의 참조·포인터 문제는 반드시 그림을 그린다.
7. 마지막에는 빈칸과 답안 번호 누락을 먼저 검사한다.
