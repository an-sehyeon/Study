# 네트워크 기초

## 1. OSI 7계층
    계층  이름          주요 기능·장비
    --------------------------------
    7    응용          HTTP,FTP,SMTP,DNS 
    6    표현          인코딩,압축,암호화 
    5    세션          연결·동기화·대화 제어 
    4    전송          TCP,UDP,포트,신뢰성 
    3    네트워크       IP,라우팅,라우터  
    2    데이터링크     프레임,MAC,스위치,HDLC   
    1    물리          비트,케이블,허브,리피터 

    PDU : 
    응용·표현·세션 : 데이터
    전송 : 세그먼트 또는 데이터그램
    네트워크 : 패킷
    데이터링크 : 프레임
    물리 : 비트

## HDLC
- HDLC는 데이터링크 계층의 비트 지향 프로토콜로 직렬 링크의 프레임 전송에 사용된다.
- Cisco 장비 문서에서도 HDLC가 직렬 인터페이스의 캡슐화 방식 중 하나로 제공되며, 일부 인터페이스에서는 기본 캡슐화로 사용된다.
