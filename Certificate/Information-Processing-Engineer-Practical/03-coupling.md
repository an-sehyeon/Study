# 결합도
- 결합도는 모듈 사이의 의존 정도다.
- 결합도는 낮을수록 좋다.

### 약한 순서
    자료 -> 스탬프 -> 제어 -> 외부 -> 공통 -> 내용

    암기 : 자스제외공내

|결합도 |설명|
|--|--|
|자료 결합도 | 필요한 단순 데이터만 전달|
|스탬프 결합도 | 구조체·객체 전체를 전달|
|제어 결합도 | 제어용 플래그 전달|
|외부 결합도 | 외부 형식·프로토콜·장치에 공동 의존|
|공통 결합도 | 전역 데이터를 공유|
|내용 결합도 | 다른 모듈 내부를 직접 참조·변경|

    좋은 설계 : 
    응집도는 높게, 결합도는 낮게
