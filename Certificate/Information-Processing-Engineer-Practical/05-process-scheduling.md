# 스케줄링

## 1. 스케줄링 비교
| 알고리즘 | 선점 여부 | 선택 기준        | 주의점             |
| ---- | ----- | ------------ | --------------- |
| FCFS | 비선점   | 도착 순서        | 호위 효과           |
| SJF  | 비선점   | 실행시간이 가장 짧음  | 긴 작업 기아 가능      |
| SRT  | 선점    | 남은 시간이 가장 짧음 | 새 프로세스 도착마다 재비교 |
| RR   | 선점    | 시간 할당량 순환    | 큐 순서 중요         |
| HRN  | 비선점   | 응답률이 가장 높음   | 긴 작업 기아 완화      |

HRN 계산 : `응답률 = (대기시간 + 실행시간) ÷ 실행시간`
응답률이 가장 높은 프로세스를 선택한다.

---

## 2. 프로세스 스케줄링 공통 공식
    반환시간 = 종료시간 - 도착시간

    대기시간 = 반환시간 - 실행시간 
             = 종료시간 - 도착시간 - 실행시간

    평균 대기시간 = 각 프로세스 대기시간 합 ÷ 프로세스 수

---

## 3. SJF
- SJF는 현재 준비 큐에 도착한 프로세스 중 실행 시간이 가장 짧은 프로세스를 선택한다.
- 비선점 방식
- 한 번 CPU를 받으면 종료할 때까지 실행한다.

### 예제
| 프로세스 | 도착 | 실행 |
| ---- | -: | -: |
| P1   |  0 |  6 |
| P2   |  1 |  3 |
| P3   |  2 |  1 |
| P4   |  3 |  2 |

#### 실행 순서
- 0ms에는 P1만 있으므로 P1 실행: `0~6 P1`
- 6ms에는 P2,P3,P4가 모두 도착. 가장 짧은 P3 선택: `6~7 P3`
- 그다음 P4: `7~9 P4`
- 마지막 P2: `9~12 P2`


    종료시간 :
    P1=6
    P2=12
    P3=7
    P4=9

    대기시간 :
    P1: 6 - 0 - 6 = 0
    P2: 12 - 1 - 3 = 8
    P3: 7 - 2 - 1 = 4
    P4: 9 - 3 - 2 = 4
    
    평균 :
    (0 + 8 + 4 + 4) ÷ 4 = 4ms

## 4. SRT
- SRT는 SJF의 선점형 방식이다.
  

    현재 실행 중인 프로세스의 남은 시간
    VS
    새로 도착한 프로세스의 실행 시간
더 짧은 프로세스가 CPU를 차지한다.

### 예제
| 프로세스 | 도착 | 실행 |
| ---- | -: | -: |
| P1   |  0 |  7 |
| P2   |  2 |  4 |
| P3   |  4 |  1 |

    종료시간 :
    P1=12
    P2=7
    P3=5
    
    대기시간 :
    P1: 12 - 0 - 7 = 5
    P2:  7 - 2 - 4 = 1
    P3:  5 - 4 - 1 = 0
    
    평균 :
    (5 + 1 + 0) ÷ 3 = 2ms

## 5. 라운드로빈 RR
- 각 프로세스에 동일한 시간 할당량을 주고 순서대로 실행한다.
    

    선점형
    시간 할당량 = Time Quantum
시간 할당량 안에 종료되지 않으면 준비 큐 맨 뒤로 이동한다.

### 문제 풀이 순서
1. 현재 준비 큐 맨 앞 프로세스를 꺼낸다.
2. min(남은 실행시간, 시간 할당량) 만큼 실행한다.
3. 실행 중 도착한 프로세스를 큐에 넣는다.
4. 실행이 끝나지 않은 현재 프로세스를 큐 뒤에 넣는다.
5. 종료시간을 기록한다.
6. 대기시간 공식으로 계산한다.

### 예제
시간 할당량 : 2ms
| 프로세스 | 도착 | 실행 |
| ---- | -: | -: |
| P1   |  0 |  5 |
| P2   |  1 |  3 |
| P3   |  2 |  4 |
| P4   |  5 |  2 |

    실행 :
    0~2   P1
    2~4   P2
    4~6   P3
    6~8   P1
    8~9   P2 종료
    9~11  P4 종료
    11~13 P3 종료
    13~14 P1 종료
    
    순서 :
    P1 → P2 → P3 → P1 → P2 → P4 → P3 → P1
    
    종료시간 :
    P1=14
    P2=9
    P3=13
    P4=11
    
    대기시간 :
    P1: 14 - 0 - 5 = 9
    P2:  9 - 1 - 3 = 5
    P3: 13 - 2 - 4 = 7
    P4: 11 - 5 - 2 = 4
    
    평균 :
    (9 + 5 + 7 + 4) ÷ 4
    = 25 ÷ 4
    = 6.25ms
