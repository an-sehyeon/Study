# CIDR와 서브넷 마스크
- IPv4 주소는 32비트이며, CIDR은 `/숫자`로 네트워크 프리픽스 길이를 표시한다.

## 1.기본 공식
    IPv4 전체 비트 = 32비트

    네트워크 비트 = CIDR 숫자
    호스트 비트 = 32 - CIDR 숫자

    전체 주소 수 = 2^(호스트 비트)
    일반적인 사용 가능 호스트 수 = 2^(호스트 비트) - 2

    -2를 하는 이유: 네트워크 주소 1개 / 브로드캐스트 주소 1개

## 2.주요 CIDR 표
| CIDR | 서브넷 마스크         | 주소 수 | 일반 호스트 수 |
| ---: | --------------- | ---: | -------: |
|  /24 | 255.255.255.0   |  256 |      254 |
|  /25 | 255.255.255.128 |  128 |      126 |
|  /26 | 255.255.255.192 |   64 |       62 |
|  /27 | 255.255.255.224 |   32 |       30 |
|  /28 | 255.255.255.240 |   16 |       14 |
|  /29 | 255.255.255.248 |    8 |        6 |
|  /30 | 255.255.255.252 |    4 |        2 |
|  /32 | 255.255.255.255 |    1 |    단일 주소 |

    마지막 옥텟 암기:
    /25 = 128
    /26 = 192
    /27 = 224
    /28 = 240
    /29 = 248
    /30 = 252
    /31 = 254
    /32 = 255
