## 학습 방법

1. 각 문서의 핵심 개념과 암기 순서를 먼저 확인합니다.
2. 계산 문제는 공식만 암기하지 않고 실행 순서와 중간값을 직접 작성합니다.
3. 코드 실행 문제는 변수와 배열이 가리키는 객체 또는 주소를 그림으로 추적합니다.
4. 기출 문제를 풀면서 틀린 개념은 해당 문서에 예제와 오답 원인을 추가합니다.
5. 시험 직전에는 각 문서의 요약·암기 영역을 중심으로 복습합니다.
