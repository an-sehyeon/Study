# 응집도

- 응집도는 한 모듈 내부 구성 요소들이 얼마나 밀접하게 관련되어 있는지를 나타낸다.
- 응집도가 높을수록 좋다.

### 강한 순서
    기능적 -> 순차적 -> 통신적 -> 절차적 -> 시간적 -> 논리적 -> 우연적

    암기 : 기순통절시논우

|응집도| 설명 |
|--|----|
|기능적|하나의 명확한 기능을 수행|
|순차적 | 한 작업의 출력이 다음 작업의 입력|
|통신적 | 동일한 입력·출력 데이터를 사용|
|절차적 | 정해진 실행 순서에 따라 수행|
|시간적 | 같은 시점에 실행되는 기능을 묶음|
|논리적 | 논리적으로 비슷한 기능을 묶음|
|우연적 | 관련 없는 기능이 임의로 묶임|

    예:
    기능적: 세금 계산 모듈
    시간적: 프로그램 초기화 시 실행할 기능 모음
    논리적: 모든 입력 처리 기능 모음
    우연적: 아무 관련 없는 함수들을 한 모듈에 배치
