# Study

자격증 공부, CS 지식, 코딩 관련 이론을 정리하고 기록하는 개인 학습 저장소입니다.

단순히 내용을 복사해 모아두는 것이 아니라, 공부한 내용을 직접 이해한 방식으로 정리하고, 나중에 다시 복습할 수 있도록 기록하는 것을 목표로 합니다.

## 목적

이 저장소는 다음과 같은 목적을 가지고 있습니다.

* 자격증 공부 내용 정리
* CS 기본 개념 정리
* 코딩 테스트 및 알고리즘 이론 정리
* Java, Spring Boot, SQL 등 개발 관련 개념 정리
* 헷갈렸던 개념과 오류 해결 과정 기록
* 면접 준비를 위한 핵심 개념 복습

## 정리할 내용

### 자격증

* 정보처리기사
* SQLD
* 기타 개발 관련 자격증 공부 내용

### CS

* 자료구조
* 알고리즘
* 운영체제
* 네트워크
* 데이터베이스
* 객체지향 프로그래밍

### Coding

* Java 문법
* SQL 문법
* 코딩 테스트 문제 풀이
* 알고리즘 개념 정리
* 자주 헷갈리는 코드 흐름 정리

### Backend

* Spring Boot
* JPA
* MyBatis
* REST API
* 인증/인가
* 프로젝트 구현 중 학습한 내용

## 기록 방식

* 개념을 처음 보는 사람도 이해할 수 있도록 쉽게 정리
* 헷갈렸던 부분은 예시와 함께 정리
* 코드가 필요한 내용은 주석을 포함해 작성
* 문제를 틀렸다면 왜 틀렸는지 함께 기록
* 실제 프로젝트나 면접에서 어떻게 연결되는지 정리

## 목표

꾸준히 공부한 내용을 기록하면서, 단순히 알고 있는 지식이 아니라 직접 설명할 수 있는 지식으로 만드는 것이 목표입니다.

또한 이 저장소를 통해 학습 과정, 개념 이해도, 문제 해결 과정을 체계적으로 관리하고자 합니다.
