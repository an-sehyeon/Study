# 쿠키, 세션, 웹 스토리지 차이

- HTTP는 기본적으로 상태를 저장하지 않는 프로토콜이다.
- 따라서 로그인 상태 유지, 사용자 설정 저장 등의 기능을 위해 쿠키, 세션, 웹 스토리지를 사용한다.

---

## 1.쿠키(Cookie)
- 쿠키는 브라우저에 저장되는 작은 데이터이다.
- 서버가 브라우저에 데이터를 저장하도록 요청할 수 있으며, 이후 요청 시 자동으로 서버에 전송된다.

### 특징
- 브라우저에 저장
- 서버로 자동 전송
- 약 4KB 크기 제한
- 만료 시간 설정 가능

### 사용 예
- 로그인 유지
- 사용자 식별
- JWT 저장

---

## 2.세션(Session)
- 세션은 서버가 사용자 정보를 저장하는 공간이다.
- 사용자가 로그인하면 서버는 세션을 생성하고, 세션 ID를 쿠키에 저장하여 사용자 상태를 관리한다.

### 특징
- 서버에 저장
- 로그인 상태 관리
- 세션 ID는 쿠키에 저장
- 쿠키보다 상대적으로 안전

#### 💡쿠키보다 세션이 상대적으로 안전한 이유
```plantuml
중요한 사용자 정보가 브라우저가 아니라 서버에 저장되기 때문.

예를 들어 쿠키에 아래처럼 저장하면
userId=1
role=ADMIN

브라우저에 값이 있기때문에 사용자가 조작할 위험이 있다.
반면 세션은 서버에 아래처럼 저장한다.
[서버 세션 저장소]
SESSION_ID:ABC123
userId: 1
role: USER

브라우저에는 실제 사용자 정보가 아니라 아래처럼 세션 ID만 저장됨.
JSESSIONID=ABC123

즉, 브라우저가 들고 있는건 "사용자 정보"가 아니라 서버 세션을 찾기 위한 열쇠.
```
그래서 정리하면
```plantuml
쿠키
-> 사용자 정보가 브라우저에 직접 저장될 수 있음
-> 조작, 탈취 위험이 큼

세션
-> 사용자 정보는 서버에 저장
-> 브라우저에는 세션 ID만 저장
-> 중요한 정보 노출 위험이 상대적으로 작음
```

### 동작 과정
1. 로그인 요청
2. 서버 세션 생성
3. 세션 ID 발급
4. 쿠키 저장
5. 요청 시 세션 ID 전송
6. 서버가 사용자 확인

### 사용 예
- 로그인 상태 유지
- 사용자 인증 및 권한 관리

---

## 3.웹 스토리지(Web Storage)
- 웹 스토리지는 브라우저에 데이터를 저장하는 HTML5 저장소이다.
```plantuml
종류
localStorage
sessionStorage
```

---

## 4.localStorage
- 브라우저에 데이터를 영구 저장하는 저장소이다.
- 브라우저를 종료해도 데이터가 유지된다.

### 특징
- 브라우저에 저장
- 서버로 자동 전송되지 않음
- 약 5MB 저장 가능
- 직접 삭제 전까지 유지

### 사용 예
- 다크 모드 설정
- 최근 검색어
- 장바구니 정보

---

## 5.sessionStorage
- 현재 브라우저 탭에서만 데이터를 저장하는 저장소이다.
- 탭을 닫으면 데이터가 삭제된다.

### 특징
- 브라우저에 저장
- 서버로 자동 전송되지 않음
- 약 5MB 저장 가능
- 택 종료 시 삭제

### 사용 예
- 회원가입 입력 데이터 임시 저장
- 결제 진행 상태 저장
- 일회성 데이터 관리

---

## Cookie, localStorage, sessionStorage 비교
|구분|Cookie|localStorage|sessionStorage|
|---|------|------------|--------------|
|저장 위치|브라우저|브라우저|브라우저|
|서버 자동 전송|O|X|X|
|저장 용량|약 4KB|약 5MB|약 5MB|
|브라우저 종료|유지 가능|유지|삭제|
|탭 종료|유지|유지|삭제|
|주요 용도|인증, 세션 유지|장기 데이터 저장|임시 데이터 저장|

---

## 핵심 정리
#### Cookie
- 브라우저 저장
- 서버 자동 전송

#### Session
- 서버 저장
- 로그인 상태 관리

#### localStorage
- 브라우저 영구 저장

#### sessionStorage
- 탭 종료 시 삭제

---

# 한 줄 요약
**쿠키는 브라우저에 저장되어 서버로 자동 전송되는 데이터이고, 세션은 서버에서 사용자 상태를 관리하는 방식이며, localStorage와 sessionStorage는 브라우저에 데이터를 저장하지만 서버로 자동 전송되지 않는 저장소이다.**
